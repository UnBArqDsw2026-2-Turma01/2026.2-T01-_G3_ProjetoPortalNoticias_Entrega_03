#### Contexto (Problema)
##### 1. Builder de notícias - João Pedro Lopes da Cruz

Pensando na funcionalidade de criar uma notícia pensei que poderia haver templatezinho de estrutura de como ficaria a página da notícia, alguns com a imagem em destaque grande, outro com apenas uma imagem pequena ao lado do texto e uma notícia que comporte um carrossel de imagens. Pensando nessas estruturas pré definidas optei por implementar a geração da página usando um builder, pois todas as notícias seguirão a mesma estrutura base de informações (mídias, texto, título, categoria, autor, etc).

##### 1. Builder de notícias


Desse modo, pedi para a inteligência artificial Gemini 3.1 pro gerar como ele imagina o diagrama do builder nesse contexto

??? note "Diagrama GoF criacional: Gemini - prompt por João Pedro Lopes da Cruz"


    Usei a inteligência artificial para me dar um norte na diagramação, contudo não gostei muito da contrução dele, uma vez que ele não usou corretamente o relacionamento entre o diretor e a interface builder. Além disso, a falta de variedade de builders concretos mostrou uma falta de proveito do polimorfismo providenciado pela interface, além de enrijecer a estrutura

    ```mermaid

    class PortalNoticiaBuilder {
    ```

Após a modelagem feita pelo Gemini, decidi enviar para o Claude Sonnet 5.5 o diagrama do Gemini e pedir para ele fazer uma estrutura mais alinhada com o exemplo dos slides, ele acabou gerando um diagrama com um embasamento melhor

??? note "Diagrama GoF criacional: Claude - prompt por João Pedro Lopes da Cruz"

    O diagrama gerado pelo Claude separa o cliente do diretor, cria dois builders concretos (texto e multimídia), aproveitando o polimorfismo da interface, e modela a mídia como uma classe própria associada à notícia.

    ```mermaid
    classDiagram
    class Client

    class DiretorDeNoticia {
        - builder: NoticiaBuilder
        + setBuilder(builder: NoticiaBuilder)
        + construirNoticiaUrgente()
        + construirNoticiaComMidia()
    }

    class NoticiaBuilder {
        <<interface>>
        + reset()
        + adicionarTitulo(titulo: String)
        + adicionarTexto(texto: String)
        + inserirTags(tags: List~String~)
        + anexarMidia(midia: Midia)
        + build() Noticia
    }

    class NoticiaTextoBuilder {
        - noticia: Noticia
        + reset()
        + adicionarTitulo(titulo: String)
        + adicionarTexto(texto: String)
        + inserirTags(tags: List~String~)
        + anexarMidia(midia: Midia)
        + build() Noticia
    }

    class NoticiaMultimidiaBuilder {
        - noticia: Noticia
        + reset()
        + adicionarTitulo(titulo: String)
        + adicionarTexto(texto: String)
        + inserirTags(tags: List~String~)
        + anexarMidia(midia: Midia)
        + build() Noticia
    }

    class Noticia {
        - titulo: String
        - texto: String
        - tags: List~String~
        - midias: List~Midia~
        + exibir()
    }

    class Midia {
        - tipo: String
        - url: String
    }

    Client ..> DiretorDeNoticia : usa
    DiretorDeNoticia o-- NoticiaBuilder
    NoticiaBuilder <|.. NoticiaTextoBuilder
    NoticiaBuilder <|.. NoticiaMultimidiaBuilder
    NoticiaTextoBuilder ..> Noticia : cria
    NoticiaMultimidiaBuilder ..> Noticia : cria
    Noticia o-- Midia
    ```

Os dois diagramas gerados por inteligência artificial não conseguiram captar corretamente a minha intenção no uso do builder. A minha ideia central era que os diferentes blocos de uma notícia aparecem em ordens diferentes escolhidas pelo jornalista, isto é, os blocos de texto, imagens, carrosséis e vídeos devem ser posicionados conforme a intenção do redator, por isso um builder usando director seria a melhor jogada, o director seria o responsável por chamar na ordem definida pelo redator os métodos que montariam a página da notícia. Desse modo, montei meu próprio diagrama para representar essa estrutura


??? note "Diagrama GoF criacional Builder: João Pedro Lopes da Cruz"

    ```mermaid
    classDiagram
    direction TB
        class Cliente {
        }

        class NoticiaDirector {
            -builder: NoticiaBuilder
            +NoticiaDirector()
            +setBuilder() void
            +construirPersonalizada() void
            +construirNoticiaPadrao() void
            -validar() void
        }

        class NoticiaBuilder {
            +reset() void
            +definirCabecalho() void
            +definirSubtitulo() void
            +definirAutor() void
            +adicionarTexto() void
            +adicionarImagem() void
            +adicionarCarrossel() void
            +adicionarTopicos() void
            +definirRodape() void
            +getResultado() Noticia
        }

        class NoticiaDestaqueBuilder {
            -noticia: Noticia
            +definirCabecalho() void
            +definirSubtitulo() void
            +definirAutor() void
            +adicionarCarrossel() void
            +getResultado() Noticia
        }

        class NoticiaCompactaBuilder {
            -noticia: Noticia
            +definirCabecalho() void
            +definirSubtitulo() void
            +definirAutor() void
            +adicionarCarrossel() void
            +getResultado() Noticia
        }

        class NoticiaMistaBuilder {
            -noticia: Noticia
            -posicaoTitulo: PosicaoTitulo
            +NoticiaMistaBuilder()
            +definirCabecalho() void
            +definirSubtitulo() void
            +definirAutor() void
            +adicionarImagem() void
            +adicionarCarrossel() void
            +getResultado() Noticia
        }

        class Noticia {
            -titulo: String
            -subtitulo: String
            -categoria: String
            -capa: ImagemBloco
            -posicaoTitulo: PosicaoTitulo
            -autor: Autor
            -dataCriacao: Date
            -blocos: List~Bloco~
            -rodape: String
            +Noticia()
            +adicionar() void
            +getDataCriacao() Date
            +renderizar() String
        }

        class Bloco {
            +renderizar() String
        }

        class TextoBloco {
        }

        class ImagemBloco {
            -url: String
            -largura: int
        }

        class CarrosselBloco {
        }

        class TopicosBloco {
        }

        <<interface>> NoticiaBuilder
        <<abstract>> Bloco

        note for Noticia "dataCriacao é gerada automaticamente
    no construtor (new Date()): nem o
    Cliente nem o Builder informam a data"
        note for NoticiaMistaBuilder "título e subtítulo ficam sobre a capa,
    na posição recebida no construtor"
        note for Noticia "As informações do autor serão obtidas pelo servidor
        (id do user no banco por exemplo)"

        Cliente --> NoticiaDirector : usa
        Cliente ..> NoticiaDestaqueBuilder : escolhe um
        Cliente ..> NoticiaCompactaBuilder : escolhe um
        Cliente ..> NoticiaMistaBuilder : escolhe um e a posição
        NoticiaDirector o--> NoticiaBuilder : builder
        NoticiaBuilder <|.. NoticiaDestaqueBuilder
        NoticiaBuilder <|.. NoticiaCompactaBuilder
        NoticiaBuilder <|.. NoticiaMistaBuilder
        NoticiaDestaqueBuilder --> Noticia : constrói
        NoticiaCompactaBuilder --> Noticia : constrói
        NoticiaMistaBuilder --> Noticia : constrói
        Noticia *-- Bloco
        Bloco <|-- TextoBloco
        Bloco <|-- ImagemBloco
        Bloco <|-- CarrosselBloco
        Bloco <|-- TopicosBloco

    ```
