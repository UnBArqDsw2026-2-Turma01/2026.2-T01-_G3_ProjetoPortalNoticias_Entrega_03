#### Artefatos individuais

??? note decorator-relatorio "Giovanna Aguiar — Gof Estrutural"

    Para a minha contribuição individual, escolhi o padrão GoF estrutural **Decorator**, aplicado à personalização da Home do Burburinho com temas comemorativos. A escolha permite acrescentar e combinar efeitos visuais por composição de objetos, mantendo essas responsabilidades separadas da classe da página base.

    ### Introdução ao padrão

    O Decorator é um padrão GoF estrutural que acrescenta responsabilidades a um objeto por composição. O componente e seus decoradores implementam o mesmo contrato, permitindo que o cliente utilize ambos da mesma forma. Cada decorador mantém uma referência ao objeto envolvido, delega a operação a ele e acrescenta sua própria contribuição.

    Como um decorador também pode envolver outro, as responsabilidades podem ser empilhadas. Isso permite combinar funcionalidades sem criar uma subclasse da página para cada combinação de efeitos.

    ### Problema no portal

    A Home do Burburinho precisa receber temas de Natal, Halloween e Dia do Estudante, preservando as notícias, comunidades e a organização visual do protótipo. Inserir as regras de todas as datas na classe da página base aumentaria o acoplamento entre o conteúdo do portal e as personalizações comemorativas.

    O Decorator permite acrescentar essas apresentações como camadas independentes. Assim, a página base continua responsável por renderizar a Home, enquanto os efeitos festivos ficam separados em classes específicas.

    ### Aplicação

    `PaginaBasePortal` renderiza a Home logada. Cada tema empilha cinco ConcreteDecorators independentes: paleta, textos, enfeites, animação e banner. O seletor alterna entre Natal, Halloween, Dia do Estudante e Padrão.

    | Participante do padrão | Elemento no projeto | Responsabilidade |
    | --- | --- | --- |
    | Component | `PaginaPortal` | Define a operação comum `renderizar(): string`. |
    | ConcreteComponent | `PaginaBasePortal` | Fornece a Home sem personalizações comemorativas. |
    | Decorator | `PaginaPortalDecorator` | Guarda a referência à página e oferece a delegação ao objeto envolvido. |
    | ConcreteDecorators | `Tema*Decorator`, `BannerFestivoDecorator`, `TextosFestivosDecorator`, `EnfeitesBordaDecorator` e `AnimacaoFestivaDecorator` | Acrescentam separadamente as cores e os efeitos da data selecionada. |
    | Client | `DecoratorDemo` | Monta a composição e apresenta o resultado na Home. |

    No Natal, por exemplo, a base é envolvida pelos decoradores de textos, enfeites, animação, banner e paleta. Ao renderizar, as chamadas chegam à página base e o resultado recebe a contribuição de cada camada. Quando o usuário volta ao Padrão, o cliente cria uma nova página sem essas camadas, evitando resíduos de estilos e elementos festivos.

    A separação facilita acrescentar ou testar um efeito isoladamente. Em contrapartida, aumenta o número de classes e torna a ordem da composição uma decisão do cliente. Os efeitos ficam nas margens para preservar a leitura; as animações respeitam a preferência de movimento reduzido do sistema.

    ### Trechos de código

    #### Componente

    A interface define o contrato compartilhado por páginas e decoradores. A implementação concreta fornece a Home sem conhecer os temas, permitindo que a personalização seja adicionada externamente.


    ```typescript
    export interface PaginaPortal {
      renderizar(): string;
    }

    export class PaginaBasePortal implements PaginaPortal {
      renderizar(): string {
        return renderizarHome();
      }
    }
    ```

    #### Decorator abstrato

    Guarda uma `PaginaPortal`, que pode ser a base ou outro decorador, e delega a renderização. Receber a interface no construtor, em vez de exigir uma página concreta, é o que permite empilhar as camadas.


    ```typescript
    export abstract class PaginaPortalDecorator implements PaginaPortal {
      constructor(protected readonly pagina: PaginaPortal) {}

      renderizar(): string {
        return this.pagina.renderizar();
      }
      protected adicionarTema(css: string): string {
        return `<section class="tema" style="${css}">
          ${this.pagina.renderizar()}
        </section>`;
      }
    }
    ```

    #### ConcreteDecorator de paleta

    `TemaNatalDecorator` herda o construtor do decorador abstrato e acrescenta somente as variáveis de cor. O helper envolve o HTML recebido sem reescrever a Home.


    ```typescript
    export class TemaNatalDecorator extends PaginaPortalDecorator {
      override renderizar(): string {
        return this.adicionarTema(
          '--destaque:#ba303b;--barra:#173b31;--fundo:#fffaf3;--cartao:#fffdf8;--texto:#172d25;--borda:#cfa85b;--suave:#52645a;',
        );
      }
    }
    ```

    #### ConcreteDecorator de banner

    Este trecho de `BannerFestivoDecorator.renderizar()` busca os dados da data e acrescenta o cabeçalho. `super.renderizar()` inclui o resultado das camadas já envolvidas; o ornamento complementar foi omitido do trecho.


    ```typescript
    const { nome, data, simbolo, mensagem } = temas[this.tema];
    return `<div class="camada-banner">
      <header class="banner-tema" role="note">
        <span class="simbolo-banner" aria-hidden="true">${simbolo}</span>
        <div><strong>${nome} · ${data}</strong><p>${mensagem}</p></div>
      </header>
      ${super.renderizar()}
    </div>`;
    ```

    #### ConcreteDecorator de animação

    Trecho de `AnimacaoFestivaDecorator.renderizar()`: acrescenta as partículas e preserva o resultado do componente envolvido por meio de `super.renderizar()`. Essa classe cuida somente da animação; banner, textos e cores são acrescentados por outros decoradores.


    ```typescript
    const particulas = temas[this.tema].particulas.map((simbolo, indice) =>
      `<span class="particula particula-${indice}">${simbolo}</span>`,
    ).join('');
    return `<div class="camada-animada">
      <div class="particulas particulas-${this.tema}" aria-hidden="true">${particulas}</div>
      ${super.renderizar()}
    </div>`;
    ```

    #### ConcreteDecorator de textos

    Trecho de `TextosFestivosDecorator.renderizar()`: adapta a saudação e o título da seção nos espaços identificados pela Home. A mesma classe também atualiza os selos dos cards, preservando os títulos das notícias e as categorias.


    ```typescript
    const { saudacao, secao, selo } = temas[this.tema];
    return super.renderizar()
      .replace(/(<h1 data-saudacao>)[^<]*(<\/h1>)/, `$1${saudacao}, ${nomeUsuario}!$2`)
      .replace(/(<h2 id="titulo-ultimas" data-titulo-secao>)[^<]*(<\/h2>)/, `$1${secao}$2`)
      // As substituições dos selos continuam no arquivo completo.
    ```

    #### Definição das camadas

    Cada data escolhe uma classe de paleta e reutiliza os decoradores das outras quatro responsabilidades. Essa lista determina quais objetos serão empilhados pelo cliente; os decoradores de banner, animação, enfeites e textos recebem a data como configuração.


    ```typescript
    const paletas = {
      natal: TemaNatalDecorator,
      halloween: TemaHalloweenDecorator,
      estudante: TemaDiaEstudanteDecorator,
    };
    const camadas = (tema: Tema): Camada[] => [
      TextosFestivosDecorator, EnfeitesBordaDecorator, AnimacaoFestivaDecorator,
      BannerFestivoDecorator, paletas[tema],
    ];
    ```

    #### Uso na Home

    O cliente começa com uma página base, envolve o resultado com cada camada da data selecionada e apresenta o HTML pelo contrato comum. O painel de demonstração aciona esse cliente, mantendo os controles separados das classes do padrão.


    ```typescript
    let pagina: PaginaPortal = new PaginaBasePortal();
    for (const tema of temas) {
      for (const Camada of camadas(tema)) pagina = new Camada(pagina, tema);
    }
    // Em DecoratorDemo.main():
    destino.innerHTML = this.compor(temas).renderizar();
    ```
